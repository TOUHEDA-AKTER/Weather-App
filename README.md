# 🌦️ Weather App

A Flutter-based Weather Application that provides current weather information and weather forecasts for different cities using the OpenWeatherMap API.

## ✨ Features

- 🌍 Search weather information by city name
- 🌡️ Display current temperature in Celsius
- ☁️ Show weather conditions
- 💨 Fetch weather information using OpenWeatherMap API
- 📅 Get 5-day weather forecast data
- 📱 Cross-platform Flutter project structure

## 🛠️ Technologies Used

- **Flutter** – UI development
- **Dart** – Application programming language
- **OpenWeatherMap API** – Weather data provider
- **HTTP** – API communication
- **JSON** – Weather data parsing

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- OpenWeatherMap API Key

### Installation

1. Clone the repository:

```bash
git clone https://github.com/TOUHEDA-AKTER/Weather-App.git
```

2. Navigate to the project directory:

```bash
cd Weather-App
```

3. Install dependencies:

```bash
flutter pub get
```

4. Configure your OpenWeatherMap API key securely.

5. Run the application:

```bash
flutter run
```

## 🌐 API Integration

This application uses the [OpenWeatherMap API](https://openweathermap.org/api) to retrieve:

- Current weather data
- City-based weather information
- Weather forecast data

**Security:** Never commit API keys or other credentials to GitHub. Use a secure configuration approach for API credentials.
